1. Executive Summary 
During the 10th week of the course, I took charge of end-to-end data processing for 103 survey responses in `data.csv` as part of the group project "Community Food Waste Recycling Survey." My tasks included early-stage data cleaning—removing Chinese text, converting yes/no fields to 1/0 numerical codes, eliminating invalid samples, and handling dummy variables—and late-stage data visualization. Initially, using GitHub Copilot with vague prompts led to data corruption and overwritten files. I then switched to Doubao, adopting a workflow of "human-defined requirements → AI-generated code → test validation," which enabled efficient creation of key visualizations: a line chart for regional recycling participation rates, a pie chart for kitchen waste disposal method distribution, and a scatter plot for recycling frequency vs. satisfaction. This experience revealed that human-defined precise requirements and clear operational boundaries unlock AI’s value, while tool selection and prompt refinement are critical for successful collaboration.
2. AI Usage Overview 
The group’s 10th-week data processing tasks unfolded in two phases: cleaning and visualization. For the early cleaning phase, I needed to process `data.csv` by removing Chinese text while retaining English, converting yes/no fields to 1/0 codes, eliminating invalid samples missing "age range" or "district," and handling dummy variables. I initially used GitHub Copilot but failed to specify critical details like "preserve the original file" and "designated fields" in my prompts. This resulted in errors: accidental deletion of English data, incomplete conversion of yes/no fields (missing 3 key fields), overwriting the original file (reducing entries from 103 to 95), and incorrect dummy variable handling. After recovering the original data by re-exporting it from the survey platform, I revised my collaboration strategy.
In the late visualization phase (second half of the 10th week), the group required a line chart, pie chart, bar chart, and forest plot. Recognizing GitHub Copilot’s limitation in generating detailed complex visualization code, I switched to Doubao—having previously experienced its more comprehensive output. I first refined requirements: clarifying chart types, data sources (cleaned `data_cleaned.csv`), axis labels, and eco-friendly style preferences. I translated these into structured prompts, such as specifying for the regional participation rate line chart: "Calculate the proportion of samples with ‘recycling participation’ = 1 for each area, sort the X-axis as ‘Downtown → Suburb → Rural’." Doubao’s code included complete logic for data reading, calculation, plotting, and saving, with parameter adjustment annotations. Through "prompt optimization → code testing → detail fine-tuning," I finished all visualization tasks in one day without data security issues.

4. Reflection on Human-AI Collaboration
Collaborating with GitHub Copilot and Doubao revealed that human-AI success hinges on "precise requirement definition" and "alignment with tool characteristics." In the early data cleaning phase with GitHub Copilot, I neglected to specify core rules like "preserve English" and "designated conversion fields" and ignored its tendency to miss details in complex multi-task processing. This led to data corruption, highlighting that vague prompts waste time and undermine task integrity. In contrast, the visualization phase with Doubao thrived because I not only refined details like data calculation logic and chart style but also leveraged Doubao’s strength in generating complete, annotated code. This showed AI tools have no inherent advantages—humans add value by selecting tools suited to tasks and translating vague needs into executable prompts.
I also repositioned AI from a "single code generator" to a "full-process visualization assistant." Instead of simply asking for a line chart, I manually decomposed logic into "data calculation → chart structure → style optimization," then guided Doubao step-by-step. For example, specifying "calculate participation rates before plotting" prevented AI from skipping critical processing, while adding style details reduced manual post-adjustments. This "human decomposes logic → AI writes code" model leveraged AI’s grammatical accuracy while ensuring alignment with requirements through human oversight. Test validation remained essential: even with Doubao’s detailed code, I used small-sample testing to verify data calculations and chart accuracy, avoiding errors from format inconsistencies.
Ethically, I learned to clarify contributions in group assignments—labeling "core data cleaning completed manually; visualization code framework assisted by Doubao; prompt design and logic validation completed by me" to avoid conflating AI outputs with personal work. Skill-wise, I mastered task-based AI selection (GitHub Copilot for simple cleaning, Doubao for complex visualization) and structured requirement decomposition. The most rewarding aspect was seeing how refined prompts transformed AI from a source of errors to a productivity booster; the biggest challenge was adapting to tool limitations and iterating on prompts. This experience showed AI excels at executing defined tasks but lacks contextual judgment—humans provide domain knowledge, logical reasoning, and critical evaluation that AI cannot replicate. For instance, when Doubao generated an overly complex multi-dimensional chart, I simplified it to align with the project’s analysis goals, a judgment AI couldn’t make independently.
Overall, the collaboration dynamic evolved from "AI-led with vague guidance" to "human-led with precise direction." I used AI as a reasoning engine by asking it to explain code logic and troubleshoot errors, not just generate outputs. When validating AI responses, I cross-checked data against original CSVs, verified code syntax, and tested edge cases—ensuring reliability. This process deepened my understanding of both data processing and human-AI synergy, showing that the most effective partnership combines AI’s efficiency with human’s critical thinking and contextual awareness.
